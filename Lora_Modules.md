# Module dimensions & formats

TCXO: SX126x and LLCC68 modules power the TCXO from DIO3; LR11xx and LR20xx modules use the chip's VTCXO pin (the LR20xx has no DIO3). Either way the firmware has to set the TCXO voltage. "No" means a plain crystal.

Pins: 2.0mm and larger castellations are easy to hand-solder. 1.27mm is manageable with care. Underside pads, LGA, or a large centre ground pad need reflow or hot air.
